# Figure and table scripts for the UCMuon paper

One script per figure of *UCMuon: A simulation suite for cosmic-ray muon
generation, transport, and muography*. The manuscript itself is not part of this
repository; these scripts are here so that every figure in it can be
regenerated from the code and the benchmark products rather than taken on
trust.

```bash
bash make_all_figs.sh          # everything, into ../figs/
python3 make_fig02_flux_spectra.py   # or one at a time
```

| Script | Figure or table |
|---|---|
| `make_fig01_pipeline.py` | Fig. 1, pipeline diagram |
| `make_fig02_flux_spectra.py` | Fig. 2, surface flux models |
| `make_fig03_zenith_dist.py` | Fig. 3, zenith distributions |
| `make_fig04_gui_screenshot.py` | Fig. 4, GUI screenshot frame |
| `make_fig05_energy_spectra.py` | Fig. 5, underground energy spectra |
| `make_fig06.py` | Fig. 6, survival curve |
| `make_fig07_scaling.py` | Fig. 7, HPC scaling (data from `run_scaling_hpc.sh`) |
| `make_fig08_source_validation.py` | Fig. 8, source-spectrum validation |
| `make_fig10_timing.py` | Fig. 10, engine timings |
| `make_fig_realistic_survival.py` | survival, realistic spectrum |
| `make_fig_realistic_timing.py` | timing, realistic spectrum |
| `make_fig_ucmugen_directed.py` | UCMuGen directed-sampling figure |
| `make_survival_table.py` | depth-resolved survival table |

Inputs come from `../../benchmark/` (summary CSVs and timing files) and, for the
depth-resolved table, from the git-ignored raw scratch tree
`benchmark/geant4_muon_rock_v5/`, which is regenerated by the benchmark
roadmap in `benchmark/README.md`. `scaling_hpc.csv` and `scaling_laptop.csv`
are the measured scaling data, kept here because they are small and are what
Fig. 7 plots.

`ucmuon_flux_models.py` and `ucmuon_run_helpers.py` are shared helpers;
`parma_vertical_spec.f90` builds the PARMA vertical spectrum used by Fig. 2.
